# templates/ · 模板规范

**模板 = 会反复产出的成品的骨架**。引擎产出成品时优先套用对应模板，保证格式一次统一、处处一致。

## 规则

1. 模板正文用 `{{变量}}` 标注需填充处；固定不变的部分直接写死。
2. 模板头部一行注明：所属引擎 + 对应 workflow/prompt。
3. 模板改版 = 全系统该类成品格式改版，属次版本变更，记 CHANGELOG。
4. 同一成品出现两种格式时，以模板为准并修掉另一处（SYSTEM.md 冲突裁决第 6 条）。
