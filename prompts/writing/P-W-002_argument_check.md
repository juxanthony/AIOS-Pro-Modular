# P-W-002 · 学术段落论证链检查

| 项 | 说明 |
|---|---|
| 场景 | proposal/论文任何章节成文后的质检（workflows/proposal_writing.md 第 5 关） |
| 变量 | {{text}} 待检段落（可多段）；{{purpose}} 本节应服务的论点（可留空） |
| 依赖 | engines/writing.md；knowledge/phd/style_guide.md 论证铁律 |
| 局限 | 检查论证结构，不核实引文真实性（那是 literature/ 库的职责） |

---

挂载写作引擎（学术语境，遵守 style_guide 论证铁律）。检查以下文字的论证链（本节论点：{{purpose}}）：

{{text}}

请执行：
1. **逐段标注**：主张 / 证据 / 推理 三件套各在哪句；缺哪件、哪件最弱；
2. **未支撑断言清单**：列出所有没有证据背书的判断句（这些要么补引用、要么降格为假设、要么删）；
3. **结构诊断**：段落主旨句是否前置？段间逻辑是否断链？与 {{purpose}} 跑偏的句子标出来；
4. **修改**：给出修订版 —— 改少而准，保留我的声音；确需重写的段落单独说明理由；
5. 不新增任何引用（引用只能来自 literature/ 库）。
