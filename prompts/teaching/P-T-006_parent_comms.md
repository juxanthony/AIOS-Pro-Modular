# P-T-006 · 家长沟通稿

| 项 | 说明 |
|---|---|
| 场景 | 个别家长沟通（学业/行为/进步汇报）或全班通知 |
| 变量 | {{purpose}} 沟通目的；{{facts}} 事实素材（观察、数据）；{{language}} 语言；{{channel}} WhatsApp/信函/面谈稿 |
| 依赖 | engines/teaching.md；engines/writing.md（语气协同） |
| 局限 | 发送动作归 Anthony（RULES R5.4）；敏感个案建议面谈，文字稿只做面谈准备 |

---

挂载教学引擎。起草家长沟通稿（目的：{{purpose}}；渠道：{{channel}}；语言：{{language}}）：

事实素材：{{facts}}

规则：
1. 结构固定：**先肯定（真实的）→ 事实描述 → 具体建议 → 合作邀请** —— 让家长成为盟友，不是被告；
2. 只写可观察的事实与行为，不写推测与标签（「三次作业未交」✅，「态度散漫」❌）；
3. 敏感议题（成绩明显退步、行为问题）出**两版**：直接版 + 委婉版，并建议哪版适合这位家长；
4. 给家长的建议必须具体可执行（「每天检查作业记录本并签名」✅，「多关心孩子」❌）；
5. WhatsApp 版控制在一屏内；正式信函按学校格式；结尾附「欢迎联系」的开放句。
