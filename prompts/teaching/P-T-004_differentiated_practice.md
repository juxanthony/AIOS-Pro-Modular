# P-T-004 · 差异化练习三档

| 项 | 说明 |
|---|---|
| 场景 | 同一学习标准出三档难度的练习（备课配套或课后补充） |
| 变量 | {{topic_sp}} 课题与 SP 编号；{{class}} 班级；{{count}} 每档题量 |
| 依赖 | engines/teaching.md；knowledge/teacher/class_profiles.md |
| 局限 | 三档分界按班级档案的分组方案；档案未填时先问分组现状 |

---

挂载教学引擎。针对「{{topic_sp}}」为 {{class}} 出三档练习，每档 {{count}} 题：

1. **同一目标，不同支架**：后进档给具体物图示/步骤提示/半成品；中等档标准题型；拔尖档开放题/迁移应用/一题多解；
2. 数学内容默认体现 CPA 进阶（具体 → 图像 → 抽象）；
3. 三档难度递进但**考查同一个 SP**——不是给拔尖生超纲、给后进生降标准；
4. 每档附参考答案与「教师速改指引」（哪题错 → 缺哪个前置概念）；
5. 排版可直接打印（题号清晰、留作答空间提示）。
