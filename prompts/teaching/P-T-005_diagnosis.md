# P-T-005 · 学情诊断与干预

| 项 | 说明 |
|---|---|
| 场景 | 成绩滑坡、概念反复出错、课堂状态异常 —— 找根因、定干预 |
| 变量 | {{situation}} 观察到的现象与数据（越具体越好）；{{scope}} 个体/小组/全班 |
| 依赖 | engines/teaching.md；knowledge/teacher/class_profiles.md |
| 局限 | 诊断基于我提供的观察；涉及疑似学习障碍/心理状况时只建议转介专业评估，不下判断 |

---

挂载教学引擎（D3 深度）。诊断以下学情（范围：{{scope}}）：

{{situation}}

请执行：
1. **5 Whys 根因分析**：从现象往下追，落到四类之一 —— 前置知识缺口 / 教学方法不适配 / 练习量与反馈 / 非学业因素（动机、环境）；证据不足的分支标「假设」；
2. **验证方式**：每个根因假设配一个低成本验证动作（如 3 道诊断题、一次课堂观察点）；
3. **干预方案**：按验证结果分别给课内（下节课就能做的调整）、课后（练习/辅导安排）、家庭（家长能配合的一件事）三层；
4. **复查标准**：两周后用什么证据判断干预有效；
5. 纪律：全程对事不对人，不用「懒、笨、不认真」类标签；疑似需要专业支持的情况明确建议转介（RULES R2/R5）。
