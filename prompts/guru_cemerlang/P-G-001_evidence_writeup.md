# P-G-001 · 实绩 → 证据条目

| 项 | 说明 |
|---|---|
| 场景 | 把一件原始实绩（口述/杂记）整理成规范证据条目（workflows/gc_application.md 第 3 关） |
| 变量 | {{raw_achievement}} 实绩的原始描述；{{evidence_available}} 手头已有的证据文件 |
| 依赖 | engines/guru_cemerlang.md；templates/gc_evidence_entry.md；knowledge/teacher/gc_profile.md |
| 局限 | 评审维度的对应关系以现行官方评审框架为准（情报关入库后才可靠） |

---

挂载 GC 引擎。把以下实绩整理成规范证据条目（格式：templates/gc_evidence_entry.md）：

实绩描述：{{raw_achievement}}
已有证据：{{evidence_available}}

规则：
1. **只写我说过的事实**，不添油加醋；成果没有数据时，用可验证的事实表述，不用空形容词（RULES R2）；
2. Impak 栏优先量化；无法量化的写「谁可以证实、怎么证实」；
3. Bukti 栏缺口逐项列【待补证：找谁、要什么、期限】；
4. 「一段话陈述」用马来文（正式文书语域），附中文回译供我核对；
5. 最后判断：此条与博士研究（数学教育）可否双向复用，一句话说明怎么用。
