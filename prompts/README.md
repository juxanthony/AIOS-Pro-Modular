# prompts/ · Prompt 库规范

可直接复用的指令库。目标形态：数千条、按域编号、检索即得（ROADMAP 第 8 周成体系）。

## 编号规则

`P-<域码>-<三位流水号>`，一条 prompt 一个文件，放对应子目录：

| 域码 | 子目录 | 领域 |
|---|---|---|
| T | `teaching/` | 教学 |
| R | `research/` | 研究 |
| W | `writing/` | 写作 |
| G | `guru_cemerlang/` | GC 申报 |
| B | `basketball/` | 篮球 |
| Y | `youtube/` | YouTube |
| A | `ai/` | AI 工程 |
| S | `system/` | 系统/元 prompt |

文件名：`P-T-001_lesson_plan.md`（编号 + 短英文名）。

## 单条 Prompt 的统一格式

```markdown
# P-X-000 · <名称>
| 场景 | 何时用这条 |
| 变量 | {{双花括号}} 列表及说明 |
| 依赖 | 需要先加载的引擎/知识文件 |
| 局限 | 已知不擅长什么 |
---
（prompt 正文，变量用 {{variable}} 标注）
---
使用记录: 次数 / 最近效果备注（复盘时更新，差评两次 → 修或删）
```

## 质量纪律

- **入库门槛**：真实用过且效果满意，预计还会用第二次（SELF_IMPROVEMENT 沉淀协议）。
- 变量化：具体人名、班级、日期一律抽成 `{{变量}}`，正文不留一次性细节。
- 编号只增不复用；删除的 prompt 移入各子目录 `_retired.md` 留档。
