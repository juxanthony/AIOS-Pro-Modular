# P-Y-002 · 选题工厂（批量生成 + 打分入池）

| 项 | 说明 |
|---|---|
| 场景 | 为某个方向批量补充选题并按池规则打分（定位实验期/常态选题） |
| 变量 | {{direction}} 方向（A 数学家长/B AI×教师/C 少儿篮球/D 教师成长/其他）；{{count}} 数量；{{seed}} 灵感种子（近期评论、课堂观察、热点，可留空） |
| 依赖 | engines/youtube_business.md；knowledge/youtube/topic_pool.md、channel_profile.md |
| 局限 | 需求分是常识初评 —— 真实需求以 YouTube 搜索联想与同类频道数据核实 |

---

挂载 YouTube 引擎。为方向 {{direction}} 生成 {{count}} 个选题（灵感种子：{{seed}}）：

规则：
1. 每个选题过**观众三问**（谁的什么问题 / 凭什么点开 / 看完得到什么），答不出的不输出；
2. 按池规则打分：需求 × 成本 × 产品链（各 1–5），标注「AI 初评待核实」；
3. 工作标题按点开动机写（好奇缺口/痛点直击/结果展示），不写内容简介式标题；
4. 每个选题附一行「产品链一句话」：看完的人下一步自然想要什么；
5. 与池内已有选题重复/近似的，标注并建议合并；
6. 输出为可直接粘贴进 topic_pool.md 的表格行。
