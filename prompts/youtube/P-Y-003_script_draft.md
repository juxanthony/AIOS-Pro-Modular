# P-Y-003 · 脚本起草（长视频 / Shorts）

| 项 | 说明 |
|---|---|
| 场景 | 选题与标题定稿后起草脚本（youtube_video_pipeline 第 3 步） |
| 变量 | {{format}} 长视频/Shorts；{{topic}} 选题（池编号+标题）；{{title}} 定稿标题；{{time_budget}} 本支制作工时预算；{{materials}} 手头素材（课堂片段/演示/白板，可留空） |
| 依赖 | engines/youtube_business.md；templates/video_script.md 或 shorts_script.md；channel_profile.md |
| 局限 | 口播习惯因人而异 —— 初稿务必朗读一遍再定稿，别扭处直接改成你的口语 |

---

挂载 YouTube 引擎。为以下选题起草 {{format}} 脚本（套对应模板）：

- 选题：{{topic}}；定稿标题：{{title}}
- 工时预算：{{time_budget}}；可用素材：{{materials}}

规则：
1. **兑现承诺**：脚本必须完整交付标题许诺的价值，且在前 30 秒（Shorts 前 2 秒）让观众确认「来对了」；
2. 按工时预算定规格：预算小 → 结构简单、镜头少、一次成型；不设计拍不动的画面；
3. 口播写成**人话**（短句、口语、有具体例子），每段标画面提示；
4. 教学类内容遵守教师本色：讲清楚「为什么」，不贩卖焦虑；
5. 长视频顺手输出 2–3 个可切出的 Shorts 钩子（写进脚本末尾备忘）；
6. 不出现可识别学生信息；使用课堂素材前提醒知情同意（RULES R5）。
