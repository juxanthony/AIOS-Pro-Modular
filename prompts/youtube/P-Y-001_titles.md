# P-Y-001 · 标题工厂

| 项 | 说明 |
|---|---|
| 场景 | 选题确定后、写脚本前的包装先行（workflows/youtube_video_pipeline.md 步骤 2） |
| 变量 | {{topic}} 选题；{{audience}} 目标观众；{{payoff}} 观众看完的获得 |
| 依赖 | engines/youtube_business.md；knowledge/youtube/channel_profile.md |
| 局限 | 平台热词时效性强，重要视频建议再人工核对当期表达 |

---

挂载 YouTube 引擎。为选题「{{topic}}」产标题（观众：{{audience}}；获得：{{payoff}}）：

1. 出 8 个候选，覆盖不同钩子类型：好奇缺口 / 数字清单 / 反常识 / 痛点直击 / 结果展示；
2. 每个标注：钩子类型 + 预估点开动机一句话；
3. 给出你的推荐 Top 2 及理由（与频道往期风格的匹配度也算进去）；
4. 红线：标题承诺的内容必须在片内兑现，不做货不对板的标题党；
5. 附每个推荐标题的封面文案（≤6 字）建议。
