挂载篮球引擎。基于以下比赛信息做复盘：

{{game_info}}

请执行：
1. **四象限**：进攻好 / 进攻待改进 / 防守好 / 防守待改进，每格 ≤3 条，全部写可观察的**行为**，不写态度标签；
2. **根因**：选最痛的 1–2 条做 5 Whys，落到「技术 / 决策 / 体能 / 心理与规则」四类之一；
3. **下周一件事**：只推荐一个训练主题 + 建议的 2–3 个对应 drill（库内优先）；
4. **球员逐人一句**：具体强项 + 一个改进点，适龄正面、点行为；用我提供的化名/号码（RULES R5）；
5. **对手情报**：提炼可回填 team_profile 的对手特点与应对（若是会再遇的对手）；
6. 信息不足的判断标注「需核实」，并列出下次比赛要专门留意的 2 个观察点。
