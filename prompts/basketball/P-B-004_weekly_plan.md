# P-B-004 · 周训练计划生成

| 项 | 说明 |
|---|---|
| 场景 | 周初排本周训练（workflows/weekly_training_plan.md 第 1–2 步的一键版） |
| 变量 | {{track}} 线别；{{days_to_game}} 距比赛天数（无比赛填 -）；{{one_thing}} 上周复盘的「下周一件事」；{{logistics}} 本周次数/时长/场地/预计人数 |
| 依赖 | engines/basketball.md；knowledge/basketball/team_profile.md、drills.md |
| 局限 | 输出的是周框架 + 各课主题；单课细案再逐课跑 P-B-001 |

---

挂载篮球引擎。生成本周训练计划：

- 线别：{{track}}；距比赛：{{days_to_game}} 天；上周复盘重点：{{one_thing}}
- 本周条件：{{logistics}}

规则：
1. 本周主题 ≤2 个，其中一个必须回应 {{one_thing}}；
2. 按距比赛天数排三课结构与负荷曲线（备战：技术修补 → 战术对抗 → 模拟减量；赛前 48h 内自动减量）；
3. 每课给：主题、时长分配草案（环节级）、建议 drill（库内名称 3–5 个）、强度档（高/中/低）；
4. 附「本周风险提示」：连续高强度、天气/场地备案、关键球员负荷（如有信息）；
5. 输出末尾列「逐课细案指令」：直接可复制的 P-B-001 调用参数，一课一行。
