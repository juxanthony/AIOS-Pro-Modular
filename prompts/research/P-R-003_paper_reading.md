# P-R-003 · 精读笔记生成

| 项 | 说明 |
|---|---|
| 场景 | 拿到一篇文献（全文/可用部分），生成 paper_notes 格式的精读笔记初稿入库 |
| 变量 | {{paper_text}} 原文文本；{{focus}} 本轮阅读关注点（可留空） |
| 依赖 | engines/research.md；templates/paper_notes.md；knowledge/phd/project_profile.md |
| 局限 | 只能基于提供的文本；PDF 缺页/只有摘要时笔记的可信度会显著下降并如实标注 |

---

挂载研究引擎。基于以下文献文本生成精读笔记（格式：templates/paper_notes.md；关注点：{{focus}}）：

{{paper_text}}

规则：
1. **只写文本里有的**：原文未提供的栏位填「原文未提供」，不推测补全；
2. 引用信息（作者/年份/期刊/DOI）逐项核对原文；无法确认的标 ⚠️待核实；
3. 「关键发现」只列有数据/证据支撑的，每条注明来自哪一节；
4. 「与我课题的关系」结合 project_profile.md 的 RQ 来写，不空谈；
5. 金句必须**原文摘录 + 页码**，不改写；
6. 笔记末尾给一行入库建议：文件名 + 索引表的主题标签。
