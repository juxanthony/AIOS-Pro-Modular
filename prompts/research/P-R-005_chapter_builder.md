# P-R-005 · 章节推进器（大纲 → 成文）

| 项 | 说明 |
|---|---|
| 场景 | proposal/论文某章节从素材到成文的推进（proposal_writing 第 5 关的主力工具） |
| 变量 | {{chapter}} 哪一章哪一节；{{materials}} 现有素材（笔记/骨架/上一稿）；{{target_length}} 目标篇幅 |
| 依赖 | engines/research.md；knowledge/phd/style_guide.md、literature/、project_profile.md |
| 局限 | 引用只能来自 literature/ 已入库笔记；素材不足时先列「还缺什么」而不是硬写 |

---

挂载研究引擎（协同 writing）。推进以下章节（目标篇幅：{{target_length}}）：

- 章节：{{chapter}}
- 现有素材：{{materials}}

分两步走，第一步确认后才进第二步：
1. **大纲**：分节结构 + 每段一句话主旨 + 每段将引用哪些库内文献 + 标出「素材缺口」（缺文献/缺数据/缺论证的段落）；
2. **成文**（确认大纲后）：按 style_guide 铁律逐段展开 —— 每段主张→证据→推理齐全；学术英文（或按课题语言规定）；写完自动过一遍 P-W-002 式论证链自检并附检查结果；
3. 全程不引入库外文献；确需新文献的位置写【需补文献：检索方向】；
4. 交付时附「与前后章节的衔接句」建议，防止章节孤岛。
