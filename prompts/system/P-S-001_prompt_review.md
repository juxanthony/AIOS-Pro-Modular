# P-S-001 · Prompt 评测与迭代

| 项 | 说明 |
|---|---|
| 场景 | 库内某条 prompt 效果不佳，或新 prompt 入库前的质检（ai_engineer 引擎的元工具） |
| 变量 | {{prompt_text}} 待评测的 prompt 全文；{{failures}} 不满意的实际输出例子（≥1 个，没有就先去攒） |
| 依赖 | engines/ai_engineer.md；prompts/README.md 格式规范 |
| 局限 | 没有失败样例时只能做静态检查，改进命中率显著下降 |

---

挂载 AI 工程引擎。评测并迭代以下 prompt：

【prompt 原文】{{prompt_text}}
【失败样例】{{failures}}

请执行：
1. **诊断**（对照失败样例逐条归因）：模糊指令（可多解）/ 缺约束（没堵住的出口）/ 缺上下文（该引用的知识文件没引用）/ 格式未定义 / 要求互相冲突 —— 指出具体是哪句的问题；
2. **重写**：给修订版全文，改动处用注释标出理由；保持库内统一格式（元信息表 + 正文 + 使用记录）；
3. **测试方案**：给 2 个测试输入（一个典型、一个边界），说明各自预期输出的判定标准；
4. **裁决建议**：修复 / 拆成两条 / 建议退役（连续两次差评的按库规则处理）；
5. 提醒我：修订后更新该 prompt 的「使用记录」备注，并跑 index_prompts.py 刷新索引。
