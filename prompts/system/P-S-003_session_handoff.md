# P-S-003 · 会话交接摘要

| 项 | 说明 |
|---|---|
| 场景 | 长会话要收尾/换平台继续（如 Claude 网页聊到一半转 Claude Code，或明天新会话接力） |
| 变量 | {{destination}} 交接去向（新会话/其他平台/未来的自己）；{{focus}} 只交接哪部分（可空 = 全部） |
| 依赖 | system/MEMORY.md（判断哪些内容该顺手沉淀入库） |
| 局限 | 交接包是压缩品 —— 关键决定的完整理由若很重要，提示我存档原文 |

---

为本次会话生成交接包（去向：{{destination}}；范围：{{focus}}）：

格式（总长 ≤300 字，可直接粘贴到新会话开头）：

```
【AIOS 会话交接】
任务：一句话说清在做什么
已完成：编号列出（只列影响后续的）
关键决定：决定 + 一句理由（防止新会话推翻重议）
未决问题：谁的输入卡住了什么
下一步：新会话的第一个动作
需加载：engines/XX + 相关 knowledge 文件路径
```

规则：
1. 只写「新会话不知道会走弯路」的信息，过程细节全部丢弃；
2. 关键决定必须带理由 —— 没有理由的决定最容易被下一个会话推翻重来；
3. 顺手检查：本会话有没有该沉淀进仓库的东西（按 MEMORY.md/SELF_IMPROVEMENT.md），有则列「待沉淀清单」附在交接包后；
4. 若去向是无文件权限的平台，把「需加载」改为「需粘贴的 bundle：dist/aios_XX.md」。
