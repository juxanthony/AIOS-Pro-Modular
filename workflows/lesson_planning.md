# Workflow: 备课（从课标到可上课的完整教案）

```yaml
模块: workflows/lesson_planning.md
版本: 0.1
状态: 骨架（第 2 周实战校准）
引擎: teaching
预计耗时: 15–25 分钟（借助 AI）
```

## 触发条件

需要为某个课标单元准备一节（或一个单元的）新课。

## 输入

- 单元/学习标准编号（查 `knowledge/teacher/subject_curriculum.md`）
- 目标班级与程度（查 `knowledge/teacher/class_profiles.md`）
- 课时长度、可用设备/场地
- 上一节课的进度与遗留问题（如有）

## 步骤

1. **定靶** —— 用逆向设计开场：写下「下课时学生要能做到什么 + 我用什么证据检验」。
   ⤷ 产物：1–2 条可检验的学习目标（对齐学习标准编号）。
2. **设计评估** —— 先出检验环节（退出券 / 随堂小测 / 表现任务），再设计教学。
   ⤷ 用 prompt `P-T-002`（出题）。
3. **设计活动链** —— 导入钩子 → 讲解/示范 → 练习（三档差异化）→ 检验 → 收束。
   ⤷ 用 prompt `P-T-001`（备课），套 `templates/lesson_plan.md`。
4. **配材料** —— 生成讲义/活动卡/板书结构；列出需要提前准备的实物。
5. **自检** —— 过一遍教案自检点（时间总和=课时？三档学生都有事做？材料清单完整？）。
6. **沉淀** —— 上完课后 3 分钟：在教案末尾记「实际效果 + 下次改什么」，好活动回填 knowledge/。

## 完成标准

教案完整到「另一位老师拿到也能照着上」；检验环节与学习目标一一对应。
