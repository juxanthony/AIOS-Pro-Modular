# Workflow: GC 申报再战（复盘 → 补强 → 提交 → 评审）

```yaml
模块: workflows/gc_application.md
版本: 0.1
状态: 试运行（今年申报的主线工作流）
引擎: guru_cemerlang（文书协同 writing）
预计耗时: 贯穿整个申报季，六关推进
```

## 触发条件

本年度 GC 申报的任何实质工作。**今年提交 —— 时间线纪律高于完美主义。**

## 输入

- `knowledge/teacher/gc_profile.md`（含上次申报复盘 —— 没填先填）
- 今年的官方申报通告（没拿到 = 第 1 关的任务）
- `knowledge/teacher/` 教学实绩素材

## 步骤（六关）

1. **情报关** —— 拿到今年的官方 pekeliling/通告：窗口日期、条件、评审流程；逐项抄进 gc_profile 条件对照表（注明文件名+日期）。
   ⚠️ AI 记忆中的申报条件一律无效，只认现行官方文件（RULES R2）。
2. **复盘关** —— 用 P-G-002 复盘上次申报：卡点诊断 → 本次必须补强的 1–3 件事（写回 gc_profile）。
3. **证据关** —— 按评审维度盘点实绩：每条用 P-G-001 + `templates/gc_evidence_entry.md` 建档；缺证据的列「补证清单」（找谁、要什么文件、期限）。
   ⤷ 数学教学创新的证据优先做厚 —— 申报科目是数学，且可双向复用于博士研究。
4. **文书关** —— 申报表格文书 + 教学创新报告（`templates/gc_innovation_report.md`，马来文，writing 引擎协同）；每份对照评审维度自评：亮点前置？证据链闭合？
5. **评审关** —— 观课准备（教学按 teaching 引擎的输出标准做到位）+ pembentangan 讲稿与幻灯 + 模拟评委问答（含「上次为什么没成」的直球问题）。
6. **提交关** —— 全套材料对照官方 checklist 核对 → 提前一周提交 → 记录提交凭证；后续跟进节点入 `knowledge/personal/current.md`。

## 完成标准

今年窗口内完成提交，全套材料过第 4 关自评；评审环节（若进入）完成至少一轮预演。

## 常见坑

- 用旧年份的条件准备材料，白做 —— 第 1 关必须先行。
- 实绩堆数量不对维度：评审看的是维度覆盖与证据链，不是厚度。
- 复盘缺失，第二次踩同一个坑 —— 第 2 关不许跳过。
- （其余边用边补）
