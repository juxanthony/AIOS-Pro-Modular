# Workflow: 频道定位决策（资产盘点 → 三环检验 → 实验 → 定案）

```yaml
模块: workflows/channel_positioning.md
版本: 0.1
状态: 试运行（起步期第一工作流 —— 定位未定前，暂缓大规模产出）
引擎: youtube_business
预计耗时: 决策 1–2 次会话；实验期 6–10 支视频（约 2–3 个月）
```

## 触发条件

频道定位未定或想转型时。**定位没过三环检验前，不投入高成本制作。**

## 输入

- `knowledge/youtube/channel_profile.md` 候选定位分析表
- 真实工时预算（每支视频可投入的小时数 —— 如实）
- 商业目标：自有产品/课程（已定）

## 步骤

1. **资产盘点** —— 确认候选方向表（现有 A 数学家长向 / B AI×教师 / C 少儿篮球 / D 教师成长），可增删。
2. **三环检验（D4 深度）** —— 每个候选逐环打分（1–5）并写一句理由：
   - ① 可持续：以我的工时预算，这个方向能不能每月稳定产出？素材是否来自我本来就在做的事（教学/训练/研究 = 零额外成本素材）？
   - ② 有需求：有明确人群在搜这些问题吗？用 YouTube 搜索联想、同类频道数据做证据（AI 判断标「待核实」，以实际检索为准）。
   - ③ 通产品：看完视频的人，顺理成章会要什么产品？产品我做得出来吗？
   ⤷ 产物：加权排序 + 推荐 Top 1–2（引擎必须给推荐，不许只摆选项）。
3. **设计实验** —— 为 Top 1–2 方向各出 3–5 支「实验视频」（从 topic_pool 取）：低制作成本、直击该方向核心需求；长短搭配（Shorts 测钩子，长视频测留存与订阅）。
4. **跑实验** —— 每支走 youtube_video_pipeline；发布后按「定位信号」判读：搜索来源占比、订阅转化、评论提问的方向性（比播放量更重要）。
5. **定案** —— 实验期结束开一次 D4 决策会话：数据 + 手感 + 意愿三对照 → 写入 channel_profile「决策记录」；定了就 10 支视频内不摇摆。
6. **定名与包装** —— 定位确定后才定：频道名、简介、封面视觉语言、固定栏目结构。

## 完成标准

channel_profile 的定位决策记录已填写（方向 + 理由 + 更新节奏承诺），观众画像一句话成立。

## 常见坑

- 用「我想做什么」代替「谁需要什么」—— 三环的 ②③ 就是解药。
- 实验期看播放量下结论 —— 起步期数据噪音大，看方向性信号（搜索来源、订阅转化、评论）。
- 定位摇摆，每支视频换一个人群 —— 算法和观众都记不住你。
