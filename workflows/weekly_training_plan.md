# Workflow: 周训练计划（比赛需求 → 三次课 → 复盘回填）

```yaml
模块: workflows/weekly_training_plan.md
版本: 0.1
状态: 试运行（备战期主线工作流）
引擎: basketball
预计耗时: 周初 15 分钟排计划，每课后 3 分钟记录
```

## 触发条件

每周初为某条线（默认校队 A）排本周训练；或赛程变化需要重排。

## 输入

- `knowledge/basketball/team_profile.md`（哪条线、距比赛几天、对手情报）
- 上周复盘的「下周一件事」（来自 workflows/game_review.md 或上周课后记录）
- 本周实际可用：次数、时长、场地、预计到场人数

## 步骤

1. **定主题** —— 从比赛需求倒推：距比赛天数 + 上场暴露的问题 → 本周 1–2 个主题（不许超过 2 个）。
2. **排周结构**（以每周 3 次为例，周末比赛情境）：
   - 课 1（周初）：技术修补日 —— 主题相关技术块加重 + 中等对抗
   - 课 2（周中）：战术对抗日 —— 条件赛/Shell/退防，强度最高的一天
   - 课 3（赛前）：模拟与减量 —— 情境 Scrimmage 走强度、罚球、定位球走位；赛前 48h 内不上新内容、不打高强度
   - 无比赛周：技术日 / 对抗日 / 比赛化日，强度递增
3. **填每课细案** —— 用 P-B-001 逐课生成（套 templates/training_session.md，drill 从库取）。
4. **负荷检查** —— 三课强度曲线合理（高-中-低向比赛收）；小学生连续高强度不超过两课；个人 C 线自训避开球队高强度日。
5. **执行与记录** —— 每课后填「课后 3 分钟」。
6. **周末回填** —— 有效的 drill 变式回写 `drills.md`；对手新情报回写 `team_profile.md`；下周主题候选记下。

## 完成标准

三次课细案齐备且强度曲线成立；周末回填完成 —— 计划、执行、沉淀闭环。

## 常见坑

- 一周塞三个主题，等于没有主题。
- 赛前一天练体能或上新战术 —— 比赛日腿是软的、脑是乱的。
- （其余实战后补）
