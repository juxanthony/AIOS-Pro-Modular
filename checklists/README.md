# checklists/ · 检查清单规范

**清单 = 漏一项就会出事的逐项核对表**。执行时逐项打勾，不凭感觉跳过。

## 规则

1. 每项一个可判定的动作句（能明确答「是/否」），不写模糊要求。
2. 清单长度控制在 15 项以内；超了说明该拆成两个场景。
3. 每次「出事后复盘」的产物优先考虑：是不是该给某清单加一项？
